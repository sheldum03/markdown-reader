# 第二阶段实施与验收

基线：安全三方合并 b7efe56 上的交接快照到 ddf7016；保留当前分支国际化、YAML、搜索和 AI 阅读版。VMark 参考提交 113ad8d（ISC）。不修改源工作区或 VMark。

1. 保真源码编辑、统一 Markdown 渲染模型 → 原文字节往返、特殊语法与无操作切换测试。
2. 块级虚拟阅读、源位置映射与分屏同步 → 千万字符样本、DOM 挂载数量、定位和响应基准。
3. 多标签、CJK、MCP → 草稿/保存/滚动/评论隔离，格式预览与撤销，工作区和写权限拒绝测试。
4. 自包含 HTML 导出和图表按需拆包 → 方言一致、离线资源、生产 manifest 和运行时加载验证。
5. 原生回归和可运行 macOS App → 前端/类型/Rust/原生 E2E、包体与性能报告、五项验收矩阵。

大文档采用 Worker 解析结构化块，视口只挂载有限块；超大单块按源码行提供有界阅读路径。源码编辑默认使用 CodeMirror，富文本保留为显式模式。MCP 使用本地 stdio 服务，以启动时授权工作区为根，写入需明确开启并检查版本，避免覆盖并发变更。
